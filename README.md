# Batch Files

A collection of Windows batch script examples for automating simple tasks.

These scripts run only on Windows and have been tested on Windows 11.

## Available Scripts

- Open a specific folder in File Explorer.

## Usage

1. Download or clone this repository.
2. Edit the folder paths in the script you want to use, if needed.
3. Double-click the `.bat` file to run it, or execute it from Command Prompt.
